# 建築工事見積もりアプリ
## 概要
このプロジェクトは、小規模な建築工事で使用することを想定した見積もりアプリです。
ユーザー毎の見積もりと詳細を管理し、情報の共有、再利用を効率的に進めることができます。
スプレッドシート等の表計算ソフトを使用している個人または中小企業での使用を想定しています。

## 工夫した点
以前に類似した工事をしている場合、既存の見積もりをベースに別件で保存できるようにしました。
JavaScriptを使用し、詳細入力中にリアルタイムに合計金額が表示されるようにしています。
